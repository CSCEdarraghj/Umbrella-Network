# Umbrella Network

Python networking toolkit for practicing diagnostics, configuration, DNS, port testing, switching, peer-to-peer communication, and web server functionality.

## Main Files

- `main.py` - main entry point
- `tools/` - diagnostics, DNS, ports, and configuration tools
- `labs/` - peer-to-peer and switching demonstrations
- `web/` - web server and related files
